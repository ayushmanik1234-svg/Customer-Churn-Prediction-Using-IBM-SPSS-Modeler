Customer Churn Prediction Using IBM SPSS Modeler

Project Details

- University: United University
- Course: BBA Final Year
- Subject: Predictive Analytics
- Software: IBM SPSS Modeler

Project Overview

This project focuses on predicting customer churn in the telecom industry using IBM SPSS Modeler.

Objective

To identify whether telecom customers are likely to remain Active or become Churned using historical customer data.

Tools Used

- IBM SPSS Modeler
- Microsoft Excel

Methodology

1. Import the training dataset.
2. Explore customer records using the Table node.
3. Define field types using the Type node.
4. Sort records using the Sort node.
5. Build classification models using the Auto Classifier node.
6. Compare model performance.
7. Apply the generated model to new customer data.
8. Analyse predicted churn and confidence values.

Results

- C5: 89.903% accuracy
- Neural Net: 88.975% accuracy
- Bayes Net: 87.637% accuracy

The model predicted 14 customers as Churned and 6 as Active.

Conclusion

This project demonstrates how predictive analytics can help telecom companies identify customers who may leave their services and support better customer retention decisions.
